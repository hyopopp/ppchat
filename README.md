# PC ↔ 폰 초간단 채팅

**파일 하나(`index.html`)만 있으면 됩니다.** 설치도, Node도, 서버도 필요 없습니다.

## 방법 1 — GitHub Pages에 올려서 쓰기 (추천)

1. GitHub에 새 저장소를 만들고 `index.html`을 업로드합니다. (파일명은 반드시 `index.html`)
2. 저장소 → **Settings → Pages** → **Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → **Save**
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 주소가 만들어집니다.
4. PC에서 이 주소를 열고 이름/방 코드를 확인한 뒤 **입장**을 누릅니다.
5. 폰에서는 상단의 **링크 복사** 버튼을 눌러 나온 주소를 카카오톡·문자로 보내고,
   폰에서 그 링크를 열면 **방 코드까지 자동으로 채워집니다.** 이름만 입력하고 입장하면 끝.

> HTTPS 주소라서 복사 기능도 문제없이 동작합니다.

## 방법 2 — 파일을 직접 열기 (업로드 없이)

1. PC에서 `index.html`을 더블클릭해서 엽니다.
2. 폰으로 파일을 보내서(카톡 '나에게 보내기', 이메일 등) 엽니다.
3. 양쪽에서 **같은 방 코드**를 입력하고 입장합니다.

같은 Wi-Fi가 아니어도(폰이 LTE/5G여도) 대화됩니다.

## 방 코드

- **랜덤 코드** 버튼으로 새로 만들 수 있고, 상단 바에서 복사할 수 있습니다.
- 대소문자 구분 없이 알파벳/숫자 3~12자면 됩니다.
- 코드가 같으면 같은 대화방입니다. 남에게 알려주지 마세요.

## 어떻게 동작하나요?

- 브라우저끼리 **공개 MQTT 중계 서버**(HiveMQ, EMQX) 2곳에 **동시에** 접속해 메시지를 주고받습니다.
- 따로 띄우는 서버가 없고, 두 중계 서버 중 하나만 살아 있어도 대화가 됩니다.
- 채팅 기록은 어디에도 저장되지 않습니다. 새로고침하면 이전 대화는 사라집니다.

## 주의

- **공개 중계 서버**를 쓰는 간단한 도구입니다. 방 코드를 아는 사람은 대화를 볼 수 있으니
  비밀번호·개인정보 같은 민감한 내용은 보내지 마세요.
- GitHub Pages(무료)는 저장소가 공개면 **주소를 아는 누구나** 페이지를 열 수 있습니다.
  (대화 내용은 방 코드를 알아야 보입니다.)
- 인터넷 연결이 필요합니다. 회사/학교 네트워크에서 WebSocket이 막혀 있으면 연결되지 않을 수 있습니다.
- 대화 기록 저장, 파일 전송, 알림 같은 기능은 없습니다. 딱 채팅만 됩니다.
